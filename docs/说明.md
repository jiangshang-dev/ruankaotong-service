# 软考通 AI 后端：配置与启动

默认端口 `9001`。需要 **JDK 21**、本机或远程 **Redis**，以及 OpenAI 兼容的大模型接口。

- Windows：编辑并双击 `docs/start.bat`
- Mac：编辑 `docs/start.sh` 后执行 `chmod +x docs/start.sh && ./docs/start.sh`
- Ubuntu / Linux 服务器：编辑 `docs/start-linux.sh` 后执行 `chmod +x docs/start-linux.sh && ./docs/start-linux.sh start`
- Docker：见文末「Docker 启动」，镜像文件是 `docs/Dockerfile`

## 模型配置

对应 `application.yml` 的 `ruankao.ai.*`，可用环境变量覆盖。

| 环境变量 | 配置项 | 说明 | 示例 |
| --- | --- | --- | --- |
| `LLM_BASE_URL` | `ruankao.ai.base-url` | OpenAI 兼容接口地址，需含 `/v1` | `https://xxx/compatible-mode/v1` 或 `http://127.0.0.1:8000/v1` |
| `LLM_MODEL_NAME` | `ruankao.ai.model-name` | 主模型名（润色、评分、论文指导） | `qwen3.8-max` |
| `LLM_API_KEY` | `ruankao.ai.api-key` | 接口密钥，必填 | `sk-...` |
| `LLM_VISION_MODEL_NAME` | `ruankao.ai.vision-model-name` | 识图模型；留空则用主模型 | `qwen-vl-max` |
| `LLM_TIMEOUT_SECONDS` | `ruankao.ai.timeout-seconds` | 单次请求超时（秒） | `180` |
| `SERVER_PORT` | `server.port` | 后端端口 | `9001` |

论文指导流式、案例分析识图走同一套 `base-url` / `api-key`。主模型不支持图片时，单独填 `LLM_VISION_MODEL_NAME`。

## Redis 配置

论文指导会话由 AgentScope 2 的 `RedisAgentStateStore` 落盘，不手写业务 List。

| 环境变量 | 配置项 | 说明 | 默认 |
| --- | --- | --- | --- |
| `REDIS_HOST` | `spring.data.redis.host` | Redis 地址 | `127.0.0.1` |
| `REDIS_PORT` | `spring.data.redis.port` | 端口 | `6379` |
| `REDIS_PASSWORD` | `spring.data.redis.password` | 密码；无密码留空 | 空 |
| `REDIS_DATABASE` | `spring.data.redis.database` | 库号 | `0` |

启动后会写入：

```
agentscope:session:{科目ID}/{论文文件名}:agent_state
```

类型为 STRING，内容是 AgentScope 的 `AgentState`（含 `context` 对话历史）。桌面端「历史记录」从这里读取。

启动前请确认 Redis 已运行，否则论文指导会连不上。

## Windows 启动

1. 安装 JDK 21，并把 `java` 加入 PATH。
2. 本机启动 Redis（默认 `127.0.0.1:6379`）。
3. 用 Maven 打一次包（仓库根目录）：

```bat
mvn -DskipTests package
```

产物：`target\ruankao-back-1.0-SNAPSHOT.jar`

4. 编辑 `docs\start.bat`，填入 `LLM_API_KEY`、模型地址和 Redis。
5. 双击 `docs\start.bat`。

## Mac 启动

1. 安装 JDK 21（可用 `brew install openjdk@21`），确认 `java -version` 可用。
2. 本机启动 Redis（默认 `127.0.0.1:6379`）。
3. 仓库根目录打包：

```bash
mvn -DskipTests package
```

4. 编辑 `docs/start.sh`，填入 `LLM_API_KEY`、模型地址和 Redis。
5. 启动：

```bash
chmod +x docs/start.sh
./docs/start.sh
```

也可临时覆盖，不必改文件：

```bash
LLM_API_KEY=sk-xxx ./docs/start.sh
```

## Ubuntu / Linux 服务器

1. 安装 JDK 21：

```bash
sudo apt update
sudo apt install -y openjdk-21-jdk
java -version
```

2. 启动 Redis（二选一）：

```bash
sudo apt install -y redis-server
sudo systemctl enable --now redis-server
```

```bash
docker run -d --name redis --restart unless-stopped -p 6379:6379 redis:latest
```

3. 把 `ruankao-back-1.0-SNAPSHOT.jar` 和 `docs/start-linux.sh` 放到同一目录（例如 `/home/node`），或在仓库根目录先打包：

```bash
mvn -DskipTests package
```

4. 填写密钥后后台启动：

```bash
chmod +x start-linux.sh
export LLM_API_KEY=sk-xxx
./start-linux.sh start
./start-linux.sh status
```

其它命令：`stop`、`restart`、`run`（前台）。日志：同目录 `ruankao-back.log`。

健康检查：http://服务器IP:9001/api/ai/essay/health

## Docker 启动

先在本机打 jar（讲义 PDF 已打进包，不必再挂目录）：

```bash
mvn -DskipTests package
```

`docs/docker-compose.yml` 按 `/home/node` 写：与 `Dockerfile`、`target/` 同目录，**不启动 Redis**，连接已有的 `my-redis`（宿主机 6379）。

把 `Dockerfile`、`docker-compose.yml` 放到 `/home/node` 后：

```bash
cd /home/node
export LLM_API_KEY=sk-xxx
docker compose up -d --build
```

密钥不要写进 Dockerfile / compose。日志：`docker logs -f ruankao-back`。

单独 `docker run`（本机 Redis 已在 6379）也可以：

```bash
docker build -f docs/Dockerfile -t ruankao-back:1.0 .
docker run -d --name ruankao-back --restart unless-stopped --network host \
  -e LLM_API_KEY=sk-xxx \
  -e SERVER_PORT=9001 \
  -e REDIS_HOST=127.0.0.1 \
  ruankao-back:1.0
```

浏览器检查：

- 健康检查：http://127.0.0.1:9001/api/ai/essay/health
- Swagger：http://127.0.0.1:9001/swagger-ui.html
