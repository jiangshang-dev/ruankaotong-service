# 软考通 AI 后端：配置与 Windows 启动

默认端口 `9001`。需要 **JDK 21**、本机或远程 **Redis**，以及 OpenAI 兼容的大模型接口。

Windows 双击 `docs/start.bat` 即可启动。先改脚本里的模型、Redis 配置，再运行。

## 模型配置

对应 `application.yml` 的 `ruankao.ai.*`，可用环境变量覆盖。

| 环境变量 | 配置项 | 说明 | 示例 |
| --- | --- | --- | --- |
| `LLM_BASE_URL` | `ruankao.ai.base-url` | OpenAI 兼容接口地址，需含 `/v1` | `https://xxx/compatible-mode/v1` 或 `http://127.0.0.1:8000/v1` |
| `LLM_MODEL_NAME` | `ruankao.ai.model-name` | 主模型名（润色、评分、论文指导） | `qwen3.8-max` |
| `LLM_API_KEY` | `ruankao.ai.api-key` | 接口密钥，必填 | `sk-...` |
| `LLM_VISION_MODEL_NAME` | `ruankao.ai.vision-model-name` | 识图模型；留空则用主模型 | `qwen-vl-max` |
| `LLM_TIMEOUT_SECONDS` | `ruankao.ai.timeout-seconds` | 单次请求超时（秒） | `180` |
| `SERVER_PORT` | `server.port` | 后端端口 | `9001` |

论文指导流式、案例分析识图走同一套 `base-url` / `api-key`。主模型不支持图片时，单独填 `LLM_VISION_MODEL_NAME`。

## Redis 配置

论文指导会话由 AgentScope 2 的 `RedisAgentStateStore` 落盘，不手写业务 List。

| 环境变量 | 配置项 | 说明 | 默认 |
| --- | --- | --- | --- |
| `REDIS_HOST` | `spring.data.redis.host` | Redis 地址 | `127.0.0.1` |
| `REDIS_PORT` | `spring.data.redis.port` | 端口 | `6379` |
| `REDIS_PASSWORD` | `spring.data.redis.password` | 密码；无密码留空 | 空 |
| `REDIS_DATABASE` | `spring.data.redis.database` | 库号 | `0` |

启动后会写入：

```
agentscope:session:{科目ID}/{论文文件名}:agent_state
```

类型为 STRING，内容是 AgentScope 的 `AgentState`（含 `context` 对话历史）。桌面端「历史记录」从这里读取。

启动前请确认 Redis 已运行，否则论文指导会连不上。

## Windows 启动

1. 安装 JDK 21，并把 `java` 加入 PATH。
2. 本机启动 Redis（默认 `127.0.0.1:6379`）。
3. 用 Maven 打一次包（仓库根目录）：

```bat
mvn -DskipTests package
```

产物：`target\ruankao-back-1.0-SNAPSHOT.jar`

4. 编辑 `docs\start.bat`，填入 `LLM_API_KEY`、模型地址和 Redis。
5. 双击 `docs\start.bat`。

浏览器检查：

- 健康检查：http://127.0.0.1:9001/api/ai/essay/health
- Swagger：http://127.0.0.1:9001/swagger-ui.html
